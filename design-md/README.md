# DESIGN.md collection

Vendored from [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) for later use as AI design-system prompts.

## What this is

Each brand folder contains a `DESIGN.md` (and often a small `README.md`) describing colors, typography, spacing, and UI rules extracted from a real website.

Drop a `DESIGN.md` into a feature (or tell the agent to follow one) to keep generated UI visually consistent.

## How we’ll use it in DGS

- Reference these when designing **new** Next.js surfaces (`/blogs`, `/services`, landing variants, etc.).
- Do **not** force these onto the WordPress homepage mirror — that page follows live WP CSS.
- Prefer writing a DGS-specific `DESIGN.md` later (Syne, cyan/coral/purple, dark cinematic agency) and use this collection as reference.
