## 2. Shared Chat Architectural Principles
1. **Human Authority**: AI assists with drafting, grading suggestions, and resume parsing, but never independently hires, rejects, or disqualifies candidates.
2. **Data Resiliency**: A candidate's examination must never be lost due to network fluctuations, device reloads, or temporary server blips.
3. **Candidate Privacy & Integrity**: Candidate assessments never leak internal evaluation rubrics, answer keys, or AI notes to the candidate. Candidate files remain strictly private behind RBAC authentication.
4. **Zero Synthetic Data**: In production, metrics, candidates, and submissions are strictly derived from real database rows. When no data exists, a clean empty state is displayed.
