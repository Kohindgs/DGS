# LLM & AI Agent Discovery Strategy

## Purpose
To ensure that autonomous AI agents, LLM search spiders (e.g., GPTBot, PerplexityBot, ClaudeBot, Google-Extended), and retrieval-augmented generation (RAG) pipelines can index D'Genius Solutions with 100% accuracy and zero hallucination.

## Implementation Architecture
1. **Public Machine-Readable Files**:
   - `/llms.txt`: Standardized concise Markdown summary covering brand identity, core services, headquarters, founders, and key case studies.
   - `/llms-full.txt`: Comprehensive full-context document detailing complete service specs, client roster (200+ brands), verified testimonials, and FAQ knowledge base.

2. **JSON-LD Schema Triangulation**:
   - Organization: `https://schema.org/ProfessionalService`, `https://schema.org/DigitalMarketingAgency`
   - Founders: Sneha Bellara & Kohin Bellara
   - Location: Khar West, Mumbai, Maharashtra 400052, India
   - Service Offerings: Enterprise SEO, Answer Engine Optimization (AEO), Generative Engine Optimization (GEO), AI Video Production, Next.js Web Development, Performance Marketing.

3. **Crawl & Parsing Optimization**:
   - Clean, server-rendered semantic HTML markup.
   - No critical text trapped behind client-side JavaScript calculations or WebGL-only scenes.
   - Lightning-fast TTFB and high Lighthouse scores for AI scraper efficiency.
